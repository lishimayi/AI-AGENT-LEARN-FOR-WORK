# KYC 实名认证系统需求文档

## 1. 需求概述

### 1.1 背景
根据监管机构要求，平台需对用户进行身份验证，以确保交易安全、防止洗钱和恐怖主义融资。KYC（Know Your Customer）系统是平台合规运营的基础设施，所有用户在使用金融相关功能前必须完成身份认证。

### 1.2 目标
- 实现用户身份信息的收集、验证与管理
- 支持多等级认证（基础认证、高级认证、企业认证）
- 满足监管机构的合规要求
- 提供安全、高效、用户体验友好的认证流程

### 1.3 适用范围
本需求适用于平台所有注册用户，按功能模块分阶段推进。

## 2. 认证等级体系

### 2.1 认证等级定义

| 等级 | 名称 | 认证要求 | 功能权限 |
|------|------|---------|---------|
| L0 | 未认证 | 无 | 仅浏览，限制交易 |
| L1 | 基础认证 | 手机号 + 邮箱 | 限额交易 |
| L2 | 高级认证 | 身份证 + 人脸识别 | 正常交易权限 |
| L3 | 视频认证 | 视频人工审核 | 提高限额 |
| L4 | 企业认证 | 营业执照 + 对公账户 | 企业用户全功能 |

### 2.2 各等级交易限额

| 认证等级 | 单笔限额 | 日累计限额 | 月累计限额 |
|---------|---------|-----------|-----------|
| L0 | 0 | 0 | 0 |
| L1 | 1,000 CNY | 5,000 CNY | 50,000 CNY |
| L2 | 100,000 CNY | 500,000 CNY | 2,000,000 CNY |
| L3 | 500,000 CNY | 2,000,000 CNY | 10,000,000 CNY |
| L4 | 无限制 | 无限制 | 无限制 |

## 3. 功能需求

### 3.1 基础信息认证（L1）

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| KYC-101 | 用户可通过手机号注册并完成验证 | P0 |
| KYC-102 | 用户可通过邮箱注册并完成验证 | P0 |
| KYC-103 | 支持手机号 + 邮箱双重绑定 | P0 |
| KYC-104 | 发送短信验证码（60秒倒计时） | P0 |
| KYC-105 | 发送邮件验证码（5分钟有效） | P0 |
| KYC-106 | 支持验证码错误次数限制（5次） | P0 |
| KYC-107 | 支持验证码过期后重新发送 | P0 |

### 3.2 身份认证（L2）

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| KYC-201 | 支持身份证信息录入（姓名、证件号、有效期） | P0 |
| KYC-202 | 支持身份证正反面照片上传 | P0 |
| KYC-203 | 支持身份证 OCR 自动识别 | P0 |
| KYC-204 | 支持活体检测（眨眼、张嘴、摇头等） | P0 |
| KYC-205 | 支持人脸识别与证件照比对 | P0 |
| KYC-206 | 认证结果即时返回 | P0 |
| KYC-207 | 支持认证失败原因展示与重新提交 | P0 |

#### 身份认证详细流程

```
┌─────────────────────────────────────────────────────────────┐
│                      身份认证流程                              │
├─────────────────────────────────────────────────────────────┤
│  1. 用户提交身份证信息                                         │
│     ├─ 姓名（必填，中文或英文）                                │
│     ├─ 证件号码（必填，18位身份证号）                           │
│     └─ 有效期（必填，格式 YYYY-MM-DD）                         │
│                                                             │
│  2. 用户上传证件照片                                          │
│     ├─ 正面照片（人像面）                                      │
│     └─ 反面照片（国徽面）                                      │
│                                                             │
│  3. OCR 自动识别并展示                                        │
│     ├─ 识别结果需用户确认                                      │
│     └─ 支持手动修正                                           │
│                                                             │
│  4. 活体检测                                                 │
│     ├─ 系统随机下发动作指令                                    │
│     ├─ 用户按指令完成动作                                      │
│     └─ 检测不通过可重试3次                                    │
│                                                             │
│  5. 人脸比对                                                 │
│     ├─ 提取证件照人脸特征                                      │
│     ├─ 提取活体检测照片人脸特征                                 │
│     └─ 相似度 ≥ 80% 通过                                      │
│                                                             │
│  6. 返回认证结果                                              │
│     ├─ 通过 → 进入 L2 认证                                    │
│     └─ 拒绝 → 显示原因，可重新提交                              │
└─────────────────────────────────────────────────────────────┘
```

### 3.3 视频认证（L3）

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| KYC-301 | 支持录制认证视频（15-30秒） | P0 |
| KYC-302 | 视频需朗读指定语句或回答随机问题 | P0 |
| KYC-303 | 视频上传至云存储（加密） | P0 |
| KYC-304 | 人工审核队列分配 | P1 |
| KYC-305 | 审核员在线审核 | P1 |
| KYC-306 | 审核结果通知用户 | P0 |
| KYC-307 | 支持申诉功能 | P1 |

### 3.4 企业认证（L4）

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| KYC-401 | 企业基本信息录入（名称、统一社会信用代码） | P0 |
| KYC-402 | 营业执照上传与 OCR 识别 | P0 |
| KYC-403 | 法人身份认证（流程同 L2） | P0 |
| KYC-404 | 对公银行账户验证（打款验证） | P0 |
| KYC-405 | 企业授权书上传与签署 | P0 |
| KYC-406 | 企业管理员账号设置 | P0 |
| KYC-407 | 支持多账号权限管理 | P1 |

#### 企业认证资料清单

| 资料类型 | 说明 | 必填 |
|---------|------|------|
| 营业执照 | 彩色扫描件或照片 | 是 |
| 法人身份证 | 正反面照片 | 是 |
| 对公账户证明 | 开户许可证或基本存款账户信息 | 是 |
| 企业授权书 | 平台指定模板，盖章签字 | 是 |
| 公司章程 | 工商登记机关盖章版 | 否 |
| 股权结构图 | 实际控制人及持股比例 | 否 |

## 4. KYC 审核规则

### 4.1 自动审核规则

| 规则编号 | 规则描述 | 处理方式 |
|---------|---------|---------|
| AR-001 | 证件照片清晰度不足 | 自动拒绝，要求重新上传 |
| AR-002 | 证件信息与录入信息不一致 | 自动拒绝 |
| AR-003 | 人脸比对相似度 < 80% | 自动拒绝 |
| AR-004 | 活体检测未通过 | 自动拒绝，提示重试 |
| AR-005 | 证件有效期已过 | 自动拒绝 |
| AR-006 | 证件号已被其他账号使用 | 自动拒绝，转人工复核 |
| AR-007 | 用户年龄 < 18岁 | 自动拒绝 |
| AR-008 | 用户在黑名单中 | 自动拒绝，通知风控 |

### 4.2 人工审核规则

| 规则编号 | 规则描述 | 处理方式 |
|---------|---------|---------|
| MR-001 | 自动审核拒绝但用户申诉 | 转人工复核 |
| MR-002 | 证件照片疑似伪造 | 转人工复核 |
| MR-003 | 企业认证资料复杂 | 转人工审核 |
| MR-004 | 单日同一用户多次认证失败 | 主动外呼确认 |

### 4.3 审核时效要求

| 认证类型 | 自动审核 | 人工审核 |
|---------|---------|---------|
| L1 基础认证 | 即时 | - |
| L2 高级认证 | 即时 | - |
| L3 视频认证 | - | 24小时内 |
| L4 企业认证 | - | 48小时内 |

## 5. 证件管理与存储

### 5.1 存储安全要求

| 要求项 | 说明 |
|-------|------|
| 加密存储 | 证件照片、视频需加密存储，密钥分离管理 |
| 水印处理 | 存储时添加「仅供XX平台认证使用」水印 |
| 访问控制 | 严格权限控制，仅审核人员和系统可访问 |
| 备份机制 | 多地域备份，防止数据丢失 |
| 有效期管理 | 到期前30天提醒用户更新 |

### 5.2 证件有效期管理

| 证件类型 | 有效期 | 到期处理 |
|---------|-------|---------|
| 居民身份证 | 通常10-20年 | 到期前30天提醒，更新后恢复功能 |
| 护照 | 通常10年 | 到期前30天提醒，更新后恢复功能 |
| 营业执照 | 通常长期有效 | 年度校验 |

|---------|---------|

## 9. 风控联动

### 9.1 KYC 与风控系统联动

| 触发条件 | 联动动作 |
|---------|---------|
| 新用户注册 | 同步至风控系统，建立用户档案 |
| 认证失败3次 | 触发风控关注，加入观察名单 |
| 认证通过 | 更新风控档案，解除部分限制 |
| 证件即将过期 | 提前预警，提醒用户更新 |
| 用户在黑名单 | 永久拒绝认证，通知风控 |

### 9.2 认证异常监控指标

| 指标 | 阈值 | 告警方式 |
|------|------|---------|
| 单日认证失败率 | > 30% | 邮件 + 短信 |
| 单日认证量 | > 10000 | - |
| 人脸比对异常 | 连续3人 < 70% | 邮件 |
| 接口响应时间 | > 3s | 短信 |

## 11. 验收标准

### 11.1 功能验收
- [ ] L1 认证：短信/邮件验证码发送与验证正常
- [ ] L2 认证：身份证 OCR 识别准确率 ≥ 95%
- [ ] L2 认证：人脸比对准确率 ≥ 99%
- [ ] L2 认证：活体检测通过率 ≥ 90%
- [ ] L3 认证：视频上传与人工审核流程完整
- [ ] L4 认证：对公账户打款验证正常

### 11.2 性能验收
- [ ] OCR 识别响应时间 ≤ 2s
- [ ] 人脸比对响应时间 ≤ 1s
- [ ] 活体检测响应时间 ≤ 3s
- [ ] 系统支持 1000+ 并发认证

### 11.3 安全验收
- [ ] 证件照片加密存储
- [ ] 敏感信息脱敏展示
- [ ] 审核日志完整记录
- [ ] 权限控制有效
