# 法币提现功能需求文档

## 1. 需求概述

### 1.1 背景
随着平台业务发展，用户对资金提取的需求日益增长。当前系统仅支持加密货币提现，无法满足用户将资产转换为法币并提取至银行账户的需求。为提升用户体验和平台竞争力，计划开发法币提现功能。

### 1.2 目标
- 支持用户将账户余额转换为法币并提现至绑定的银行账户
- 提供清晰的提现流程和状态追踪
- 确保符合监管要求的KYC和反洗钱检查
- 实现T+1到账机制，保障资金安全

### 1.3 适用范围
本需求适用于平台所有已完成实名认证的用户。

## 2. 功能需求

### 2.1 银行账户管理

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| FB-001 | 用户可添加、编辑、删除提现银行账户 | P0 |
| FB-002 | 支持添加多家银行的账户 | P0 |
| FB-003 | 银行账户需进行实名认证校验 | P0 |
| FB-004 | 支持设置默认提现账户 | P1 |

#### 详细说明
- 每位用户最多绑定 **5个** 银行账户
- 账户姓名必须与实名认证姓名一致
- 支持的银行列表：工商银行、农业银行、中国银行、建设银行、交通银行、招商银行、民生银行、兴业银行等

### 2.2 提现申请

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| FB-010 | 用户可发起法币提现申请 | P0 |
| FB-011 | 支持输入提现金额或选择全部提现 | P0 |
| FB-012 | 显示实时汇率和预估到账金额 | P0 |
| FB-013 | 提现前需二次验证（短信/邮箱/谷歌验证码） | P0 |
| FB-014 | 提现手续费计算与展示 | P0 |
| FB-015 | 单笔提现限额检查 | P0 |

#### 业务规则
- **最小提现金额**：100 CNY
- **最大提现金额**：500,000 CNY/笔
- **手续费率**：0.1%（最低 2 CNY，最高 50 CNY）
- **到账时间**：工作日 24 小时内（T+1）

### 2.3 提现记录与状态追踪

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| FB-020 | 用户可查看提现历史记录 | P0 |
| FB-021 | 支持按时间范围、状态筛选记录 | P1 |
| FB-022 | 实时显示提现处理状态 | P0 |
| FB-023 | 提现成功/失败时发送通知 | P0 |

#### 提现状态流转
```
提交申请 → 审核中 → 处理中 → 已打款 → 已到账
                ↓
            审核拒绝 → 已退回
                ↓
            处理失败 → 已退回
```

### 2.4 风控与合规

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| FB-030 | 日累计提现限额：1,000,000 CNY | P0 |
| FB-031 | 月累计提现限额：5,000,000 CNY | P0 |
| FB-032 | 单日提现次数限制：10次 | P0 |
| FB-033 | 大额提现（>100,000 CNY）需人工审核 | P0 |
| FB-034 | 触发风控规则时自动拦截并通知用户 | P0 |

## 3. 非功能需求

### 3.1 性能要求
- 提现申请接口响应时间 ≤ 500ms
- 支持并发提现申请 ≥ 1000 TPS

### 3.2 可用性要求
- 系统可用性 ≥ 99.9%
- 提现功能维护窗口：每周日凌晨 2:00-6:00

### 3.3 安全要求
- 所有敏感操作需日志记录
- 提现密钥需加密存储
- 资金操作需多签机制

## 4. 用户流程

### 4.1 首次提现流程

```
1. 用户进入「提现」页面
2. 系统检查实名认证状态
   ├─ 未认证 → 跳转至实名认证页面
   └─ 已认证 → 继续下一步
3. 用户绑定银行账户（姓名自动填充）
4. 用户输入提现金额
5. 系统计算手续费和汇率
6. 用户确认提现信息
7. 用户完成二次验证
8. 系统提交提现申请
9. 展示申请成功和预计到账时间
```

### 4.2 再次提现流程

```
1. 用户进入「提现」页面
2. 选择已绑定的银行账户（或新增账户）
3. 输入提现金额
4. 确认并提交
5. 完成二次验证
6. 申请成功
```

## 6. 异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| 余额不足 | 提示用户余额不足，展示可提现金额 |
| 银行账户无效 | 提示用户检查账户信息或更换账户 |
| 超过日限额 | 提示用户明日再试或降低金额 |
| 汇率波动超限 | 自动拒绝申请，提示用户重新操作 |
| 审核超时 | 24小时未处理自动退款至账户 |
| 银行打款失败 | 人工介入处理，原路退回 |
