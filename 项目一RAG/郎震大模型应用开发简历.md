**项目描述：**

3. <text style="color:#253144">构建企业知识 RAG Pipeline，将 PRD、接口文档、业务流程文档等非结构化数据进行解析、切片、Embedding，建立语义检索能力。</text>

**项目二：BitV Trading Agent V1**

**项目所属：**<text style="color:#253144">HighBlock Limited（个人主导 / 进行中项目）</text></br>
**项目描述：**

- <text style="color:#253144">面向合规虚拟货币交易所（CEX）的自然语言交易 Agent，基于 LangGraph 构建多步任务状态机，封装沙盒交易工具，支持"查行情 → 评估风险 → 下单 → 监控"全链路闭环。配套沙盒撮合引擎、预交易风控护栏与人机协同机制，所有交易在内存撮合沙盒内完成（非真实交易），可作为生产级 Agent 工程化落地参考。</text>

**核心工作：**

1. <text style="color:#253144">设计 Agent Loop 状态机，覆盖意图解析、任务规划、风控校验、执行、监控 5 个节点，支持人机协同（Human-in-the-loop）与异常分支路由。</text>
2. <text style="color:#253144">封装 LangChain @tool 工具（行情查询 / 账户管理 / 下单 / 撤单 / 价格提醒），全部使用 Pydantic v2 Schema 约束入参，降低幻觉导致的非法下单。</text>
3. <text style="color:#253144">自研内存撮合引擎（订单簿 + 撮合即写库），内置 BTC/ETH/SOL 30 天历史 K 线与实时价格游走，零外部依赖即可演示与回放。</text>
4. <text style="color:#253144">设计预交易风控 Guardrails（余额 / 单笔限额 / 冷静期 / 标的校验），高风险操作（如单笔 > 5000 USDT）触发 Human-in-the-loop 二次确认。</text>
5. <text style="color:#253144">接入 LangSmith 实现全链路 Trace 可观测；编写 50 条 golden cases 自动化评估，意图识别准确率 92%、工具调用准确率 88%。</text>
6. <text style="color:#253144">FastAPI + WebSocket 提供流式对话接口，前端 Streamlit 演示页支持自然语言下单、持仓实时刷新与 LangSmith Trace 一键跳转。</text>

**技术架构：**

- <text style="color:#253144">Agent Framework：LangGraph（状态机 + Checkpointer + Human-in-the-loop）</text>
- <text style="color:#253144">LLM：GPT-4o-mini / 智谱 GLM-4（OpenAI 兼容接口可切换）</text>
- <text style="color:#253144">Tools：LangChain @tool + Pydantic v2 Schema</text>
- <text style="color:#253144">Exchange：自研内存撮合引擎（订单簿 / 成交 / 持仓全持久化）</text>
- <text style="color:#253144">Risk：预交易风控 + 二次确认 + Prompt Injection 黑名单</text>
- <text style="color:#253144">Backend：Python · FastAPI · WebSocket</text>
- <text style="color:#253144">Database：PostgreSQL · Redis</text>
- <text style="color:#253144">Frontend：Streamlit</text>
- <text style="color:#253144">Observability：LangSmith Trace</text>
- <text style="color:#253144">Eval：50+ golden cases · 三层指标（意图 / 工具 / 端到端）</text>
- <text style="color:#253144">Deployment：Docker Compose</text>

**项目成果：**

1. <text style="color:#253144">实现自然语言到沙盒交易的端到端闭环，典型场景「BTC 跌破 6.5 万时分 3 笔买入 1000 USDT」可由 Agent 自主拆解、风控校验、执行并持续监控。</text>
2. <text style="color:#253144">沙盒环境下自动化评估覆盖，意图识别 92% / 工具调用 88%，LangSmith Trace 支持端到端回放与问题定位。</text>
3. <text style="color:#253144">形成可复用的 CEX Agent 工程模板（工具封装 + 沙盒撮合 + 风控护栏 + 评估体系），便于后续迁移到真实业务系统。</text>
