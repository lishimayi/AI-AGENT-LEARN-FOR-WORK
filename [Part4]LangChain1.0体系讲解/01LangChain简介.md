# 第一阶段：架构简介
> LangChain 是一个构建LLM应用的框架，目标是把LLM和外部工具，数据源和复杂工作流连接到一起 支持从简单的promote封装到复杂的Agent（调用工具，做决策，执行多步任务）。它不仅仅是LLM API的封装，而是提供了一套完整的工具和架构，让用户能够轻松地构建同时具备上下文感知和推理能力的AI应用。LangChain1.0 版本把 Agent稳定化、结构化输出、可观测性、生产化，作为核心改进目标。

## langchain 能做什么？

* 构建Retrieval-Agumented Generation(RAG)问答系统。
* 把LLM当做“Agent”调用外部API（搜索，数据库，文件系统）获取返回结果。
* 组织prompt➡️LLM➡️后处理可复用流水线（chains）
* 实现多轮对话带记忆（memory） 与 长会话管理
* 在生产中管理可观测行和评估（配合 LangSmith 和 LangGraph）

> 核心价值：让开发者用10行代码完成原本需要1000行代码的应用，并且自动获得`状态持久化、人工敢于、并发控制`的企业级能力。

> langchain 1.0 结构风格概括：以“统一智能体抽象 + 标准化内容表示 + 可插拔治理中间件”为设计骨干，以 lang graph为底座运行时，实现“开发简单性”和“生产可控性”的兼顾。它一方面以 create_agent 提供低门槛的构建入口，另一方面又预留了足够的钩子点和下探能力，以满足复杂化的工作流和高标准的治理需求。
 
## 什么时候使用lang chain

* 简单对话，不需要，原生 chat gpt api 即可满足
* 需要websearch，执行代码、操作数据库 ：langchain
* 复杂的业务流程（多人审批，定时任务，状态分支）：langgraph
