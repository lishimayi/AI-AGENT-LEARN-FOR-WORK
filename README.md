## conda 命令
| 命令                               | 作用                   |
| -------------------------------- | -------------------- |
| `conda env list`                 | 查看所有环境（带 `*` 的是当前环境） |
| `conda create -n 名字 python=3.11` | 创建新环境，指定 Python 版本   |
| `conda activate 名字`              | 切换到某个环境              |
| `conda deactivate`               | 退出当前环境，回到 base       |
| `conda env remove -n 名字`         | 删除某个环境               |
| `conda rename -n 旧名 新名`          | 重命名环境                |
